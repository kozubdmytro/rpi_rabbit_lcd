# Smart Rabbit LCD — handoff

Актуально на 16 ноября 2026.

## Задача и состояние

Независимая копия текущего рабочего дерева
`D:/desktop/raspberry pi/test screen and ssh`, включая его незакоммиченный
cleanup. Исходный проект не изменялся.
Новая папка: `D:/desktop/raspberry pi/lcd version rpi rabbit`.
Репозиторий: https://github.com/kozubdmytro/rpi_rabbit_lcd.git, ветка main.

Пользователь разрешает коммиты и push. Запрещает установку на его Pi без
отдельной команды. При отклонении от плана нужно спросить, предложив
минимум два варианта. Проверки должны быть минимальными и осмысленными.

## Реализовано

- HUB75 заменён Linux framebuffer backend в `src/lcd_renderer.cpp`.
- Экран строго 480x320; исходный UI строго 64x64, увеличение каждого
  пикселя ровно в блок 5x5. Область 320x320 находится в x=80..399,
  y=0..319. По сторонам только чёрный фон. Нет растяжения/сглаживания.
- Форматы RGB truecolor 16/24/32 bpp, каналы/stride/offsets берутся из
  framebuffer API. Неподходящий режим отклоняется явно.
- `/dev/fb1` по умолчанию; `--fb PATH` выбирает другое устройство.
- Brightness 0..100% реализована умножением RGB; подсветка не управляется.
- MPR121 и его I2C-драйвер удалены из копии. HUB75-зависимость и
  fix-hub75-audio.sh не перенесены. Make/CMake используют LCD backend.
- Отрисовка `HubDemo`, шрифты, меню, анимации и логика жестов сохранены.
  Изменены только тип входного sample и include. `GestureSample` постоянно
  сообщает отсутствие касания. Пользователь прямо отложил объяснение
  нового управления до следующего шага; XPT2046 пока не читается.
- Mesh, BlueZ, NetworkManager, BLE Wi-Fi flow, сайт и Pixel Studio
  скопированы без изменения. Ключи, mesh-state, .local и ssh.md не перенесены.
- README описывает LCD-вариант. Старые BLE-документы исторические.

## Важные ограничения при продолжении

XPT2046 — контроллер касания, не идентификатор LCD-контроллера.
Для аппаратного запуска нужен установленный драйвер конкретной платы,
предоставляющий framebuffer 480x320. Приложение не устанавливает overlays
и не меняет boot config. Другой процесс/console не должен рисовать в тот
же framebuffer. Пример systemd unit сохраняет исходный install path
`/home/srlab/smartrabbit-test`; перед будущей установкой проверить путь.

Сохранять совместно gateway.conf и BlueZ Mesh storage. Не удалять ключи,
не переиспользовать адреса, не запускать --create-network для восстановления.
Не запускать одновременно исходный хаб и копию на одном устройстве/state.
Старое состояние/адрес BME-ноды из исходного handoff не означает наличие
такой ноды в этой новой копии. Climate использует реальные показания
назначенной BME-ноды, остальные типы остаются симуляцией исходного проекта.

Следующий шаг: получить от пользователя требования к управлению.
